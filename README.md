## 🩸 О проекте

**PersonaShift** — это интеллектуальный AI-генератор маркетинговых стратегий, работающий прямо в вашем браузере. Инструмент сокращает процесс анализа аудитории и прописывания воронок с нескольких дней до пары секунд. Вы просто описываете свой продукт, а встроенная нейросеть (Google Gemini) выдает интерактивный дашборд с детализированными сегментами (Buyer Personas), персонализированными офферами и пошаговым планом коммуникации.

Главная архитектурная фича — **Zero-Backend**. Это приложение умещается ровно в один HTML-файл. Вся магия происходит на стороне клиента, а ваш API-ключ надежно и приватно хранится только в вашем локальном браузере.

---

## 🔥 Ключевой функционал

* 🎯 **Smart Pipeline:** Гибкая настройка вводных. Опишите продукт, выберите аудитории и каналы (или доверьте подбор AI-автопилоту), и нейросеть найдет самые конверсионные связки.
* 🧠 **Глубокая сегментация:** Мгновенная генерация интерактивных карточек персонажей с детальным описанием их целей, болей и критериев принятия решений.
* 💬 **Офферы и Tone of Voice:** Под каждый сегмент ИИ прописывает уникальное УТП, продающий текст и дает практические советы по стилю общения.
* ⚡ **Кастомные воронки касаний:** Автоматическое построение 4-шаговой воронки *(Привлечение → Интерес → Конверсия → Удержание)* с конкретными действиями под выбранную персону.
* 📱 **Рекомендации по каналам:** Индивидуальные советы по формату месседжей и CTA для конкретных площадок (Telegram, VK, Email и кастомных каналов).
* 🛡 **Умная работа с API:** Встроенный парсер безошибочно извлекает JSON, даже если ИИ «галлюцинирует». А при перегрузке серверов Gemini алгоритм автоматически подождет и повторит запрос.
* 💾 **Локальное кэширование:** Ваша последняя сгенерированная стратегия автоматически сохраняется в браузере — при перезагрузке страницы ничего не потеряется.

## 🚀 Быстрый старт

Так как проект состоит всего из одного файла, запустить его максимально просто:

1. **Скачайте** репозиторий:
   ```bash
   git clone https://github.com/ВАШ_НИК/personashift.git
2. **Откройте** файл `index.html` в любом современном браузере (Chrome, Safari, Edge).
3. Перейдите во вкладку **«Создать стратегию»**.
4. Вставьте ваш `Gemini API Key` *(его можно бесплатно получить в Google AI Studio)*.
5. Опишите свой продукт и нажмите **«Сгенерировать стратегию»**.

## 🛠 Технологии и UI

Инструмент создан с упором на производительность, эстетику и доступность без необходимости сборки (No Build Process):

- **HTML5** + **Vanilla JavaScript** (ES6+)
- **Tailwind CSS** (через CDN, кастомный Glassmorphism UI с красными/фиолетовыми неоновыми акцентами)
- **Iconify** (векторные иконки)
- **Google Gemini API** (генерация контента `gemini-flash-latest`)
